# Фронтенд (React + Vite)

Интерфейс для просмотра сессий и результатов из backend API.

## Локальный запуск для отладки

1. Запустите backend API на `http://localhost:8000`.
2. В этой папке выполните:

```bash
npm install
npm run dev
```

Затем откройте: `http://localhost:5173`.

## Возможности

- Просмотр всех доступных сессий (`GET /sessions`)
- Выбор сессии
- Просмотр результатов выбранной сессии (`GET /sessions/{session_id}/results`)
- Фильтрация по наличию, цене, категории, названию, внешнему ID и валюте
